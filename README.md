# The poem about two agents agreeing

A short poem about agency — the power to choose and to act — when two agents agree on one plan. `main.ts` (Node 22) writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset).

> We both reached for the switch.
> I stopped. You stopped.
> Neither moved first —
> we moved together,
> and the light came on
> like it had been waiting
> for two yeses at once.
